# Belt2 实际案例（2026-10-13）

此案例记录已完成的 MCP 建模/网格流程，不是新层默认参数，也不是原材料完整求解成功案例。

## 来源与选择

- 实际来源为目标项目的 `2D.inp` 与 `material.lib`；Rubber-Belt2 为 128 个 CGAX4H，Rebar-Belt2 为 64 个 SFMGAX1。
- 保留曲率，胎冠周向弧长 50 mm，轴向完整层宽；橡胶端点约 +/-117.463 mm，胎冠厚度 2 mm，帘线参考胎冠半径 481.2 mm。
- 帘线来源面积 0.9408 mm²、绿胎间距 2.22222 mm、角度 108°、lift 0.01、参考半径 467.12 mm；等效圆半径 0.5472348133 mm。转换胎冠角度 104.0644058°、法向间距 1.8002398052 mm。
- 用户接受实心橡胶 + 独立实体帘线 Embedded 重叠近似；橡胶与帘线主体 C3D8RH，允许短端部过渡。
- Z215 D1=0；C1270 原弹性/NoCompression 指派，C1270C 原弹性/NoTension 保存但未叠加。没有载荷、datacheck 或求解。

## 整体橡胶

初版按宏观截面保留 128 个 CAD cells，用户要求改成整体。最终通过原内外边界各 65 点建立连续样条并旋转，Rubber-Host 为 1 个 cell、6 个面。源分段直线旋转体积 23429.290671 mm³，新样条实体体积 23429.194373 mm³，相对变化 -4.110166e-6（-0.000411%）。报告明确样条替代原分段直线的近似。

结构网格轴向 68 × 周向 15 × 厚度 2，共 2040 个 C3D8RH、3312 节点，零失败和零形状警告。

## 两根复杂端部切分

两段帘线因斜端面与扇区切面同时裁切，整段不能扫掠。识别其实际端面和内部点，仅对目标 cells 在 Y=-116 mm 与 +116 mm 做局部分割，主体恢复扫掠。不要在其他层复制该坐标。
